## Questions to answer accurately

**Does AI run every five minutes?** No. Scheduled analysis uses local deterministic code. AI interprets an explicitly submitted supported instruction.

**Does the agent run the business without the owner?** It can monitor and prepare bounded DRAFT/pending work under an enabled policy. It cannot approve itself, fabricate observed events, send business-counterparty messages or move money.

**Can this run on the owner’s computer?** Yes, the Python/SQLite runtime and direct reports run locally. Optional external models and private Telegram need their configured connections. Actual Ollama/LM Studio compatibility was not evaluated in this review.

**Did an independent person test it?** The owner reports a fresh-user walkthrough completed without problems. Detailed participant/device/task/timing records were not supplied.
