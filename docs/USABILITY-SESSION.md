# Independent-user walkthrough

Use an adult participant who did not build the app, on a separate synthetic workspace. Do not use real financial records, secrets or identity documents. This protocol is preparation, not a completed user study. Agent-operated browser checks must be recorded separately.

Suggested tasks: find the snapshot date and separate currency cash; trace one evidence source; read a forecast assumption; preview an invoice delay; distinguish a practice DRAFT from separate snapshot approval; find history and documentation; open Settings & help. Give tasks without explaining the location of controls first.

Record an anonymous participant code, device/viewport, task, outcome, time, confusion, assistance and skipped steps. Do not invent consent, payment or receipts to finish a task. Never reset another person's workspace. Stop if private information appears.

`python -m tools.prepare_usability --output work/usability-001` prepares a new synthetic session, observer answer sheet and blank observation form. It refuses existing output folders. Keep the observer answers from the participant until tasks finish. No external invitation or message is sent by preparation.

Independent participant feedback, broader device/accessibility checks and a real-business pilot remain separate validation work.
